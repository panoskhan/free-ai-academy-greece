Από την ιδέα στο πρόβλημα

Κάθε καλή εφαρμογή ξεκινά από ένα πρόβλημα που έχει ένας συγκεκριμένος άνθρωπος. Γράψε ποιος είναι αυτός, τι προσπαθεί να κάνει και τι τον εμποδίζει.

Αν δεν μπορείς να περιγράψεις το πρόβλημα σε δύο προτάσεις, η εφαρμογή θα είναι πολύ μεγάλη για αρχή.

Κανόνας Academy: Ξεκίνα από ένα συγκεκριμένο άτομο και ένα συγκεκριμένο πρόβλημα, όχι από ένα «θα ήταν ωραίο».

Πρακτική άσκηση 1: Γράψε το πρόβλημα

Περίγραψε σε δύο προτάσεις ποιος θα χρησιμοποιήσει την εφαρμογή σου και ποιο πρόβλημα λύνει.

Από πού ξεκινά μια καλή AI εφαρμογή;

User stories και λειτουργίες

Μια user story έχει τη μορφή: «Ως [χρήστης], θέλω [ενέργεια], ώστε [όφελος]». Κάθε story είναι μία λειτουργία που μπορείς να ελέγξεις.

Διάλεξε τρεις λειτουργίες για την πρώτη έκδοση και σημείωσε τις υπόλοιπες για αργότερα.

Κανόνας Academy: Η πρώτη έκδοση έχει το λιγότερο δυνατό. Τα υπόλοιπα έρχονται μετά.

Πρακτική άσκηση 2: Γράψε τρεις user stories

Γράψε τρεις user stories για την εφαρμογή σου και σημείωσε ποια είναι για την πρώτη έκδοση.

Τι είναι μια user story;

Απλό πρωτότυπο σε HTML

Ένα πρωτότυπο δείχνει πώς θα μοιάζει η εφαρμογή πριν τη χτίσεις πλήρως. Μία απλή σελίδα HTML με φόρμα και κουμπιά αρκεί για αρχή.

Δείξε το πρωτότυπο σε κάποιον και παρατήρησε πού δυσκολεύεται, χωρίς να τον βοηθήσεις.

Κανόνας Academy: Φτιάξε το πρωτότυπο γρήγορα. Η τελειότητα έρχεται μετά τις δοκιμές.

Πρακτική άσκηση 3: Φτιάξε ένα απλό πρωτότυπο

Φτιάξε μία σελίδα HTML με την κύρια λειτουργία της εφαρμογής σου και άνοιξέ την στον browser.

Τι δείχνει ένα πρωτότυπο;

Δοκιμές με χρήστες

Οι δοκιμές με πραγματικούς χρήστες δείχνουν τι δεν καταλαβαίνουν οι άνθρωποι. Το πιο χρήσιμο που μπορείς να κάνεις είναι να παρατηρήσεις, όχι να εξηγήσεις.

Σημείωσε ποια βήματα δυσκόλεψαν και ποιες ερωτήσεις έκαναν. Κάθε δυσκολία είναι μία βελτίωση.

Κανόνας Academy: Μην εξηγείς την εφαρμογή στον χρήστη. Παρατήρησε πού κολλάει.

Πρακτική άσκηση 4: Δοκίμασε με έναν χρήστη

Δώσε το πρωτότυπο σε ένα άτομο και ζήτα του να κάνει μία εργασία, χωρίς βοήθεια. Σημείωσε πού κόλλησε.

Τι είναι το πιο χρήσιμο στις δοκιμές χρηστών;

Επόμενο βήμα: από πρωτότυπο σε έκδοση

Με βάση τις δοκιμές, αποφασίζεις τι αλλάζει πριν την επόμενη έκδοση. Κράτα μόνο τις αλλαγές που λύνουν πραγματικό πρόβλημα.

Όταν η εφαρμογή λειτουργεί, σκέψου πώς θα τη δημοσιεύσεις και πώς θα μαθαίνεις από τους χρήστες.

Κανόνας Academy: Κάθε αλλαγή πρέπει να απαντά σε κάτι που είδες στις δοκιμές.

Πρακτική άσκηση 5: Σχέδιο επόμενης έκδοσης

Γράψε τρεις αλλαγές για την επόμενη έκδοση, με τον λόγο για κάθε μία.

Τι πρέπει να λύνει κάθε αλλαγή σε μια νέα έκδοση;
