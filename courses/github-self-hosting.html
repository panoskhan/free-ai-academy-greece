Το repository σου

Ένα repository είναι ο φάκελος του project σου με ιστορικό αλλαγών. Κάθε commit είναι ένα σημείο στο οποίο μπορείς να επιστρέψεις.

Γράψε ένα καλό commit μήνυμα που λέει τι άλλαξες.

Κανόνας Academy: Ένα commit με σαφές μήνυμα βοηθά τον εαυτό σου και τους άλλους.

Πρακτική άσκηση 1: Δημιούργησε repository

Φτιάξε repository για το project σου και κάνε το πρώτο commit.

Το README και η άδεια χρήσης

Το README εξηγεί τι κάνει το project, πώς εγκαθίσταται και πώς χρησιμοποιείται. Η άδεια (LICENSE) λέει τι επιτρέπεται να κάνει ο άλλος με τον κώδικα.

Χωρίς άδεια, ο κώδικας δεν θεωρείται ελεύθερος για χρήση.

Κανόνας Academy: Πρόσθεσε πάντα LICENSE που ταιριάζει στον στόχο σου. Αν δεν είσαι σίγουρος, ζήτα συμβουλή.

Πρακτική άσκηση 2: Γράψε README και πρόσθεσε άδεια

Γράψε README με σκοπό, εγκατάσταση και χρήση, και πρόσθεσε LICENSE.

Τι λέει η άδεια (LICENSE) ενός project;

Μυστικά, κλειδιά και ασφάλεια

Μην ανεβάζεις ποτέ κλειδιά API, κωδικούς ή προσωπικά δεδομένα σε repository. Ακόμα κι αν το αφαιρέσεις αργότερα, παραμένει στο ιστορικό.

Χρησιμοποίησε αρχείο .gitignore για να αποκλείσεις τοπικά αρχεία με μυστικά.

Κανόνας Academy: Αν ένα κλειδί βγει σε public repository, ακύρωσέ το αμέσως. Μην περιμένεις να το αφαιρέσεις.

Πρακτική άσκηση 3: Έλεγξε για μυστικά

Έλεγξε τα αρχεία του repository για κλειδιά ή κωδικούς και πρόσθεσε .gitignore.

Τι κάνεις αν ένα κλειδί API βγει σε public repository;

Φιλοξενία και οδηγίες για άλλους

Self-hosting σημαίνει ότι φιλοξενείς μόνος σου την εφαρμογή σε δικό σου server ή υπολογιστή. Γράψε οδηγίες ώστε κάποιος άλλος να την ανεβάσει χωρίς να σε ρωτήσει.

Κάθε βήμα πρέπει να είναι σαφές και επαληθεύσιμο.

Κανόνας Academy: Ένας άλλος developer πρέπει να μπορεί να τρέξει το project χωρίς να σε ρωτήσει για βασικά βήματα.

Πρακτική άσκηση 4: Γράψε οδηγίες μεταφοράς

Γράψε βήμα προς βήμα πώς θα τρέξει κάποιος το project σε άλλο server.

Τι σημαίνει self-hosting;

Τελική εργασία

Παραδοτέο: repository και οδηγίες ανάπτυξης

Δημοσίευσε το project σου σε repository (public ή private, ανάλογα με τον στόχο σου) με README, άδεια, χωρίς μυστικά και με οδηγίες ανάπτυξης.
