GitHub & Self-Hosting

Μάθε να κρατάς τον κώδικά σου δικό σου, να κάνεις version control και να δημοσιεύεις web projects χωρίς κλείδωμα σε μία πλατφόρμα.

1. Git και GitHub

Git καταγράφει αλλαγές στον κώδικα. GitHub φιλοξενεί repositories και συνεργατικές ροές εργασίας.

git init
git add .
git commit -m "First project"
git branch -M main
git remote add origin YOUR_REPOSITORY
git push -u origin main

2. Τι σημαίνει self-hosting;

Self-hosting σημαίνει ότι έχεις εσύ τον έλεγχο του περιβάλλοντος όπου τρέχει το project. Μπορεί να είναι δικός σου server ή άλλος πάροχος hosting.

  • Κράτησε backup.
  • Ενημέρωνε dependencies.
  • Χρησιμοποίησε HTTPS.
  • Μην αποθηκεύεις secrets στο repository.
  • Περιορίζεις δικαιώματα και πρόσβαση.

3. Public repository checklist

  • README με σκοπό, εγκατάσταση και χρήση.
  • LICENSE που ταιριάζει στο project.
  • Μην ανεβάζεις API keys, passwords ή προσωπικά δεδομένα.
  • Σαφείς οδηγίες deployment.
  • Κατάλληλο .gitignore.

🧪 Practical Lab #5

  1. Δημιούργησε repository για το project του προηγούμενου lab.
  2. Πρόσθεσε README.
  3. Κάνε το πρώτο commit.
  4. Δημοσίευσε τον κώδικα.
  5. Γράψε οδηγίες για το πώς θα το μεταφέρει κάποιος σε άλλο server.
  6. Έλεγξε ότι δεν υπάρχει secret μέσα στο repository.

Παραδοτέο: public ή private repository σύμφωνα με τον στόχο σου, README και deployment notes.

🏁 Τελικός έλεγχος

Ένας άλλος developer πρέπει να μπορεί να καταλάβει τι κάνει το project και να το τρέξει χωρίς να χρειάζεται να σε ρωτήσει για βασικά βήματα.
