Prompt Engineering

Μάθε να δίνεις στο AI σαφείς οδηγίες, να αξιολογείς το αποτέλεσμα και να βελτιώνεις το prompt αντί να μαντεύεις.

1. Το καλό prompt έχει στόχο

Ένα prompt δεν χρειάζεται να είναι «μαγικό». Ξεκίνα με το αποτέλεσμα που θέλεις και δώσε αρκετό πλαίσιο ώστε το μοντέλο να καταλάβει την εργασία.

Στόχος: Εξήγησε την έννοια του API σε αρχάριο. Κοινό: άτομο χωρίς προγραμματιστική εμπειρία. Μορφή: 5 σύντομα bullets + 1 απλό παράδειγμα. Γλώσσα: Ελληνικά. Περιορισμός: απόφυγε τεχνική ορολογία χωρίς εξήγηση.

2. Η δομή που θα χρησιμοποιούμε

  1. Στόχος: τι θέλω να πετύχω;
  2. Πλαίσιο: τι πρέπει να γνωρίζει το AI;
  3. Κοινό: για ποιον είναι το αποτέλεσμα;
  4. Μορφή: πώς θέλω να παρουσιαστεί;
  5. Κριτήρια: τι σημαίνει καλή απάντηση;
  6. Έλεγχος: τι πρέπει να επαληθεύσω;
Σημαντικό: Περισσότερες λέξεις δεν σημαίνουν πάντα καλύτερο prompt. Η σαφήνεια και η σωστή πληροφορία έχουν μεγαλύτερη αξία από το περιττό κείμενο.

3. Βελτίωση με επανάληψη

Το πρώτο αποτέλεσμα είναι συχνά προσχέδιο. Δες τι λείπει και πρόσθεσε συγκεκριμένο κριτήριο.

Αρχικό: «Γράψε μου μια περιγραφή για μια εφαρμογή.»

Βελτιωμένο: «Γράψε περιγραφή 80–100 λέξεων για μια δωρεάν εφαρμογή εκμάθησης AI στα ελληνικά. Απευθύνεται σε αρχάριους. Τόνισε πρακτική μάθηση, projects και self-hosting. Μην χρησιμοποιήσεις υπερβολικές υποσχέσεις.»

🧪 Practical Lab #2 — Φτιάξε το δικό σου prompt

Αποστολή: δημιούργησε ένα reusable prompt για μια πραγματική εργασία που κάνεις συχνά.

  1. Γράψε τον στόχο.
  2. Περιέγραψε το κοινό ή το πλαίσιο.
  3. Όρισε τη μορφή απάντησης.
  4. Βάλε 2–3 κριτήρια ποιότητας.
  5. Πρόσθεσε έναν κανόνα επαλήθευσης.
  6. Δοκίμασέ το δύο φορές και βελτίωσέ το.

Παραδοτέο: αποθήκευσε το τελικό prompt και ένα σύντομο «τι άλλαξα και γιατί».
