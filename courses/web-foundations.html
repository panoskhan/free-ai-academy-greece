Τι θα μάθεις σε αυτό το μάθημα

Το Web Foundations είναι το πρώτο τεχνικό βήμα της Academy. Πριν φτιάξεις εφαρμογές με AI, χρειάζεται να καταλαβαίνεις πώς στήνεται μια web σελίδα: τι κάνει το HTML, πώς το CSS αλλάζει την εμφάνιση και πώς η JavaScript προσθέτει αλληλεπίδραση. Όταν ένα εργαλείο AI σου προτείνει κώδικα, αυτές οι γνώσεις σού επιτρέπουν να τον διαβάσεις, να τον ελέγξεις και να τον διορθώσεις αντί να τον αντιγράφεις στα τυφλά.

  • Να γράφεις σωστό, σημασιολογικό HTML με headings, λίστες, links και κουμπιά.
  • Να κάνεις μια σελίδα responsive με CSS και @media queries, ξεκινώντας από το κινητό.
  • Να συνδέεις JavaScript με γεγονότα (events) όπως το κλικ και να αλλάζεις περιεχόμενο στη σελίδα.
  • Να ελέγχεις την προσβασιμότητα με πληκτρολόγιο και να κάνεις debugging με τα Developer Tools του browser.

Για ποιον είναι

Η δομή με HTML

Το HTML ορίζει τη δομή μιας σελίδας: τίτλους, παραγράφους, λίστες, εικόνες και links. Ο browser διαβάζει αυτή τη δομή και τη μετατρέπει σε σελίδα που βλέπεις.

Ένα βασικό σκελετός είναι το <!doctype html>, η γλώσσα (lang="el") και το <title>.

Κανόνας Academy: χρησιμοποίησε το σωστό στοιχείο για κάθε περιεχόμενο. Ένα κουμπί είναι <button>, όχι <div>.

Πρακτική άσκηση 1: Φτιάξε τον σκελετό

Δημιούργησε ένα αρχείο index.html με doctype, lang="el", title, ένα h1 και μία λίστα με 3 στοιχεία.

Η εμφάνιση με CSS και responsive design

Το CSS ορίζει εμφάνιση: χρώματα, μεγέθη, διαστάσεις και διάταξη. Με @media αλλάζεις τη διάταξη για κινητά, ώστε η σελίδα να διαβάζεται σε μικρή οθόνη χωρίς οριζόντια κύλιση.

Κανόνας Academy: σχεδίασε πρώτα για κινητό και μετά για μεγάλη οθόνη. Ελέγχεις το αποτέλεσμα σε μικρό πλάτος.

Αλληλεπίδραση με JavaScript

Η JavaScript αντιδρά σε ενέργειες του χρήστη, αλλάζει το περιεχόμενο της σελίδας και μπορεί να συνδέεται με APIs. Κράτα τη λογική απλή: χώρισε τα δεδομένα, την εμφάνιση και τις λειτουργίες.

Παράδειγμα:
document.querySelector('#hello').addEventListener('click', () => {
  document.querySelector('#message').textContent = 'Γεια σου!';
});

Προσβασιμότητα και debugging

Χρησιμοποίησε σωστή ιεραρχία headings (h1, h2, h3). Τα interactive στοιχεία πρέπει να λειτουργούν και με πληκτρολόγιο. Μην βασίζεσαι μόνο στο χρώμα για να μεταφέρεις πληροφορία.

Όταν κάτι δεν δουλεύει, μην αλλάζεις τυχαία κώδικα. Αναπαρήγαγε το πρόβλημα, διάβασε το μήνυμα σφάλματος και άλλαξε ένα πράγμα κάθε φορά.

Πρακτική άσκηση 4: Έλεγχος με πληκτρολόγιο

Πλοηγήσου στη σελίδα μόνο με το πληκτρολόγιο (Tab). Σημείωσε αν κάθε κουμπί και link έχει σαφή σκοπό.

Συχνά λάθη αρχαρίων

  • Ξεχασμένο <meta name="viewport">: χωρίς αυτό η σελίδα εμφανίζεται μικροσκοπική στο κινητό, ακόμη κι αν έχεις γράψει media queries.
  • Λάθος διαδρομή αρχείου: αν το style.css ή το script.js δεν φορτώνει, έλεγξε το όνομα και τον φάκελο στο tab Network των Developer Tools.
  • JavaScript πριν από το HTML: αν το script τρέχει πριν υπάρξει το στοιχείο, το querySelector επιστρέφει null. Βάλε το script στο τέλος του body ή χρησιμοποίησε defer.
  • Κουμπιά φτιαγμένα από div: δεν λειτουργούν με πληκτρολόγιο ούτε με screen reader. Χρησιμοποίησε <button>.
  • Εικόνες χωρίς alt: κάθε εικόνα με νόημα χρειάζεται σύντομη περιγραφή.
