🎛️ Workflow controls

Αυτό το dashboard είναι UI prototype: αποθηκεύει μόνο local workflow state. Δεν δημιουργεί repository, δεν αποθηκεύει GitHub credentials και δεν κάνει production deployment από μόνο του.

Άνοιγμα BuilderLaunch checklist

🔐 GitHub connection design

Προτεινόμενη πραγματική υλοποίηση: GitHub App/OAuth με ελάχιστα permissions → δημιουργία/ενημέρωση repository → commit SHA → GitHub Actions status → preview URL → explicit production confirmation.
Δεν κάνουμε: password collection, token paste σε public form ή arbitrary code execution στους Academy servers.
