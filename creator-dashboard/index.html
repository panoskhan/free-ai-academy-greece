🔐 Security boundary

Ποτέ: password collection, public token forms ή arbitrary creator-code execution στην Academy υποδομή.
Επόμενη πραγματική υποδομή: GitHub App/OAuth → repository → commit → CI → preview → explicit production approval → external deployment.
