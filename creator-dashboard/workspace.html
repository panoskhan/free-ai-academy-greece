🔐 Ownership model

White-label principle: creators should own the generated content and control where their Academy is hosted. The Academy project provides the learning framework and tooling; it should not quietly lock creators into one host.

A future server-backed version can support authenticated organizations, multiple projects, team roles, repository connections and audit logs. This static prototype intentionally does not pretend those server features already exist.
