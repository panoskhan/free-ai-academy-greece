🔐 Required audit fields

  • event ID and timestamp
  • actor / authenticated creator
  • academy ID
  • repository and commit SHA
  • environment and target URL
  • QA run ID and result
  • deployment ID and result
  • rollback relationship when applicable

Safety rule

UI state is not audit evidence. A production event is considered real only when the backend/provider returns a verifiable result and the audit record stores the corresponding identifiers.
