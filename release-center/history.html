↩️ Rollback policy

  1. Identify the last known-good production commit.
  2. Confirm the current production target.
  3. Run QA against the rollback candidate.
  4. Require explicit production approval.
  5. Deploy the selected known-good commit through the actual hosting provider.
  6. Verify the published URL after deployment.

Important: αυτή η στατική σελίδα δεν κάνει πραγματικό rollback. Η πραγματική λειτουργία πρέπει να χρησιμοποιεί repository/deployment APIs και να καταγράφει commit SHA, actor, time και result.

🔐 Safety rules

Ποτέ μην θεωρείς ένα rollback επιτυχημένο επειδή άλλαξε ένα local UI state. Επιτυχία σημαίνει πραγματικό deployment result και επιβεβαιωμένο published endpoint.
